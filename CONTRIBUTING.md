# Contributing

Submit a concrete public task and its visible result. Include the original source URL, publisher, date, task, media and any limitations. A complete prompt is optional and is not a condition of inclusion.

Use the original creator's post when available. Distinguish the publisher from the creator, preserve the source's model labels, and avoid treating an Arena display name as proof of its backend version. Keep failed attempts, elapsed time and selection such as “best of 4” when reported.

Reposts belong with the existing work. Different visible outputs may remain separate even when they share a subject. A comparison using an existing output belongs with that case.

Edit the curated dataset and locale copy, rebuild all README files, and run the commands in [maintenance](docs/maintenance.md). Do not edit generated README files alone.
