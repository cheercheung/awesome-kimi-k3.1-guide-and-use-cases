## 🍌 紹介

投稿者が Kimi K3.1 によるものとして公開したデモと非公式評価を集めています。匿名チェックポイント Kibitz の事例も含みます。

**元の情報源を通じて具体的なタスク、見える出力、実用上の制約を確認できます。**

<a id="overview"></a>
## 📊 概要

6分類、40件の独立した活用事例。同じ作品の転載や比較は一つにまとめています。

> [!NOTE]
> Kibitz と Kimi K3.1 の対応は未確認です。モデル名、時間、費用、品質評価は情報源の申告です。録画だけではコードの実行、全操作の正しさ、再現性は証明できません。
