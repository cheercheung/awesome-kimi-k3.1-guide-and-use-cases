# Maintenance

`data/kimi-k3-1-usecase-curated.json` is the source of truth for case identity, order, categories, source attribution, original text, metrics, media and dates. `data/locales/*.json` contains the translated visible copy. `docs/update-log.md` is the complete generated Markdown case register. Dates are the UTC publication dates of the primary sources. `README.md` is the curated English Markdown presentation; all README files are generated by `scripts/build_readmes.py`.

## Updating the collection

1. Read each source and inspect its media. Require a concrete task or output, public attribution and a clear evidence boundary.
2. Reconcile the work with existing cases. Group reposts and comparisons of the same output; retain distinct views and opposing experiences.
3. Preserve source-reported timings, failures and anonymous-checkpoint uncertainty. Public model names are source labels, not independent identity verification.
4. Preserve original URLs and source text. Host every retained visual on R2; video posters must link to their playable video. Comparison images keep their model labels.
5. Update the canonical English copy, then every locale. Keep case numbers, anchors, sources, dates and media unchanged across languages.
6. Rebuild English first, inspect it, then rebuild all languages and inspect wide and narrow renderings.

```sh
python3 scripts/build_readmes.py --english-only
python3 scripts/build_readmes.py
python3 scripts/build_readmes.py --check
```

Media downloads under `assets/media/` are working files ignored by Git. The generated repository depends on public R2 URLs rather than those downloads. Source media and works retain their original rights. Use the correction issue form for disputed attribution, incorrect claims or removal requests.

## Shared banner

All 11 README versions use the same owner-supplied English brand banner, hosted on R2. Its canonical URL and shared-r2 policy are in the curated JSON. Preserve the original banner when rebuilding README files.

## Case format

Each work has one stable `case-N` anchor and one heading linking the title to the original source and the author to their profile. Follow it with a bold usage takeaway, source-content notes, every retained image or playable video poster, and `Type: … | Date: YYYY-MM-DD`. Allowed types are Demo, Tutorial, Evaluation, Integration, Benchmark and Limit. Keep the single Menu table and inline-comma creator acknowledgement consistent across all locales.
