## 🍌 介绍

按来源署名收集 Kimi K3.1 和 K3.1 Pro 的社区演示、工作流与评估，包含早期匿名检查点 Kibitz 的录屏。

**通过原始来源了解具体任务、可见产物和实际限制。**

<a id="overview"></a>
## 📊 概览

共 125 个独立使用案例，覆盖 6 类。同一作品的转载与对比合并呈现。

> [!NOTE]
> Kibitz 与 Kimi K3.1 Pro 的对应关系仍未确认。型号、耗时、费用和质量判断均来自来源自述。录屏不能证明代码可运行、交互完整或结果可重复。

<a id="quick-start"></a>
## ⚡ 快速开始

1. 在目录选择任务。
2. 打开视频或图片，再通过案例标题访问原帖。
3. 对照任务与限制判断可见结果。

[打开 Kimi 官方网站](https://www.kimi.com/)
