## 🍌 소개

Kimi K3.1과 K3.1 Pro의 커뮤니티 데모, 작업 흐름 및 평가를 출처와 함께 모았습니다. 익명 체크포인트 Kibitz의 초기 녹화도 포함합니다.

**원본 출처를 통해 구체적인 작업, 눈에 보이는 결과와 실제 한계를 살펴보세요.**

<a id="overview"></a>
## 📊 개요

6개 분류의 독립 사례 125개입니다. 같은 작품의 재게시와 비교는 하나로 묶었습니다.

> [!NOTE]
> Kibitz와 Kimi K3.1 Pro의 대응 관계는 여전히 확인되지 않았습니다. 모델명, 시간, 비용과 품질 평가는 출처의 보고입니다. 녹화만으로 실행 가능한 코드, 완전한 상호작용이나 재현 가능한 성공을 입증할 수 없습니다.

<a id="quick-start"></a>
## ⚡ 빠른 시작

1. 목차에서 작업을 고릅니다.
2. 동영상이나 이미지를 열고 사례 제목을 통해 원문을 확인합니다.
3. 작업 및 한계와 실제 화면을 비교합니다.

[Kimi 공식 웹사이트 열기](https://www.kimi.com/)
