## 🍌 소개

게시자가 Kimi K3.1 결과로 소개한 커뮤니티 데모와 비공식 평가 모음입니다. 익명 체크포인트 Kibitz 사례도 포함합니다.

**원본 출처를 통해 구체적인 작업, 눈에 보이는 결과와 실제 한계를 살펴보세요.**

<a id="overview"></a>
## 📊 개요

6개 분류의 독립 사례 40개입니다. 같은 작품의 재게시와 비교는 하나로 묶었습니다.

> [!NOTE]
> Kibitz와 Kimi K3.1의 대응 관계는 확인되지 않았습니다. 모델명, 시간, 비용과 품질 평가는 출처의 주장입니다. 녹화만으로 코드 실행, 완전한 상호작용이나 재현성을 입증할 수 없습니다.

<a id="quick-start"></a>
## ⚡ 빠른 시작

1. 목차에서 작업을 고릅니다.
2. 동영상이나 이미지를 열고 사례 제목을 통해 원문을 확인합니다.
3. 작업 및 한계와 실제 화면을 비교합니다.

[Kimi 공식 웹사이트 열기](https://www.kimi.com/)
